## 🌟 Overview
**CookSmart** is an interactive, responsive Single-Page Application (SPA) designed to make recipe discovery, weekly meal planning, and culinary learning effortless. Featuring an interactive canvas grid background, an OGL WebGL recipe slider, dark luxury glassmorphism UI, a multilingual rule-based AI Chef Assistant, and offline LocalStorage database persistence.

---

## 🚀 Quick Setup & Run Instructions

1. Open terminal inside the `Source Code` directory:
   ```bash
   cd "Source Code"
   ```
2. Install npm dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open your browser and navigate to `http://localhost:5173`.

---

## 🛠️ Technology Stack
* **Framework**: React 18 / Vite
* **Styling**: Tailwind CSS + Custom 3D Glassmorphism
* **Graphics & Animation**: OGL WebGL, GSAP, Interactive Grid canvas, and CSS animations
* **Icons**: Lucide React
* **Database & Persistence**: JSON Pre-populated Data + HTML5 LocalStorage
